# МатеМагия: План тестирования

## 1. Описание методов тестирования

### 1.1. Аттестационное тестирование
Аттестационное тестирование — процесс проверки системы конечными пользователями или заказчиком для подтверждения того, что реализованное приложение соответствует заявленным функциональным требованиям и спецификации. Данный вид ручного тестирования эффективен для обнаружения несоответствий интерфейса и логики на финальных этапах перед аттестацией проекта.

### 1.2. Интеграционное тестирование
Интеграционное тестирование — фаза проверки, в ходе которой отдельные программные модули и слои системы (представления Views, сервисы Services, модели Models/ORM и база данных SQLite) объединяются и тестируются в составе единых цепочек взаимодействия. Позволяет выявить ошибки межмодульного обмена данными.

### 1.3. Блочное тестирование
Модульное (блочное) тестирование — автоматизированная проверка корректности работы отдельных изолированных единиц исходного кода (методов сервисов, валидации форм, свойств моделей). Позволяет быстро обнаруживать регрессионные ошибки при изменении кодовой базы проекта.

## 2. Аттестационные тесты

### 2.1. Перечень аттестационных тестов (A1–A38)

#### Тест A1 (1.1 ФТ)
- **Описание:** Проверка успешной регистрации с помощью логина и пароля.
- **Тип теста:** Позитивный.
- **Исходное состояние:** Пользователь находится на странице регистрации (вкладка «Регистрация»).
- **Сценарий:** Пользователь вводит валидные логин (например, `alisa5`), пароль, имя «Алиса» и класс «5 класс» и нажимает кнопку «Зарегистрироваться».
- **Ожидаемый результат:** Учётная запись создана, пользователь авторизован и перенаправлен в личный кабинет (`/profile/`).

#### Тест A2 (1.2 ФТ)
- **Описание:** Проверка успешного входа в систему по логину и паролю.
- **Тип теста:** Позитивный.
- **Исходное состояние:** Пользователь находится на странице авторизации (заголовок «С возвращением, маг!»). В системе есть пользователь `alisa5`.
- **Сценарий:** Пользователь вводит логин `alisa5` и верный пароль и нажимает кнопку «Войти в мир магии».
- **Ожидаемый результат:** Вход выполнен, пользователь перенаправлен на главную страницу (`dashboard_main.html`) с блоком текущего ранга.

#### Тест A3 (1.2 ФТ)
- **Описание:** Проверка успешного выхода из системы.
- **Тип теста:** Позитивный.
- **Исходное состояние:** Пользователь авторизован и находится на любой странице приложения.
- **Сценарий:** Пользователь нажимает кнопку выхода из системы.
- **Ожидаемый результат:** Сессия завершена, открыта главная страница для гостя; при обращении к `/profile/` происходит перенаправление на страницу входа.

#### Тест A4 (1.3 ФТ)
- **Описание:** Проверка просмотра основных результатов обучения в личном кабинете.
- **Тип теста:** Позитивный.
- **Исходное состояние:** Пользователь авторизован, у него есть решённые задания и полученное достижение.
- **Сценарий:** Пользователь открывает личный кабинет (`/profile/`).
- **Ожидаемый результат:** Отображаются профильный блок с рангом и шкалой опыта, карточки показателей (решено заданий, процент верных), блоки «Слабые места» и «Последние попытки».

#### Тест A5 (2.1 ФТ)
- **Описание:** Проверка просмотра списка математических тем.
- **Тип теста:** Позитивный.
- **Исходное состояние:** Пользователь авторизован и находится на главной странице.
- **Сценарий:** Пользователь нажимает пункт меню «Темы».
- **Ожидаемый результат:** Открывается страница «Книги заклинаний» со списком карточек тем, статусами («Новая», «В процессе», «Пройдена») и индикаторами прогресса.

#### Тест A6 (2.2 ФТ)
- **Описание:** Проверка выбора математической темы.
- **Тип теста:** Позитивный.
- **Исходное состояние:** Пользователь находится на странице «Книги заклинаний».
- **Сценарий:** Пользователь нажимает на карточку темы «Обыкновенные дроби».
- **Ожидаемый результат:** Открывается страница выбранной темы с описанием, списком уроков и кнопкой перехода к практике.

#### Тест A7 (2.3 ФТ)
- **Описание:** Проверка просмотра теоретического материала по выбранной теме.
- **Тип теста:** Позитивный.
- **Исходное состояние:** Пользователь находится на странице темы «Обыкновенные дроби».
- **Сценарий:** Пользователь открывает первый урок темы.
- **Ожидаемый результат:** Отображается страница теории: заголовок урока, текст с правилами и примерами, блок «Запомни!», оглавление темы и индикатор «Урок 1 из N».

- **Исходное состояние:** Пользователь ранее решил несколько заданий по теме «Обыкновенные дроби» (тема имеет статус «В процессе» или «Пройдена»).
- **Сценарий:** Пользователь открывает тему, нажимает кнопку перехода к практике и решает ещё одно задание.
- **Ожидаемый результат:** Система выдаёт задание по теме; новая попытка сохраняется, предыдущая история решений не удаляется, счётчик решённых заданий по теме увеличивается.

- **Тип теста:** Позитивный.
- **Исходное состояние:** Пользователь находится на странице выбора заданий (`/tasks/`).
- **Сценарий:** Пользователь выбирает тему и поочерёдно каждый из пяти форматов: выбор ответа, ввод значения, сопоставление пар, правда/ложь, расстановка действий.
- **Ожидаемый результат:** Для каждого формата открывается задание соответствующего типа с подходящими элементами ввода ответа.

- **Сценарий:** Пользователь переходит к заданию.
- **Ожидаемый результат:** На странице тренажёра отображены заголовок темы, формат задания и полный текст условия. Правильный ответ и объяснение не отображаются.

- **Сценарий:** Пользователь выбирает один из вариантов и подтверждает ответ.
- **Ожидаемый результат:** Ответ принят системой и отправлен на проверку, на странице появляется результат проверки.

#### Тест A12 (3.4, 3.5 ФТ)

- **Тип теста:** Позитивный.
- **Исходное состояние:** Пользователь находится на странице задания «Чему равна сумма 1/4 + 2/4?».
- **Сценарий:** Пользователь выбирает вариант «3/4» и подтверждает ответ.
- **Ожидаемый результат:** Система определяет ответ как верный и отображает результат «верно» в блоке обратной связи.

- **Сценарий:** Пользователь просматривает блок обратной связи.
- **Ожидаемый результат:** Отображается объяснение правильного решения (при верном ответе) либо информация о допущенной ошибке и объяснение (при неверном ответе).

- **Ожидаемый результат:** Тренажёр без сообщений об ошибке выдаёт заранее подготовленное задание из базы данных по выбранной теме.
